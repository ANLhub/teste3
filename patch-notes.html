Notas de atualização

Resumo das melhorias e novidades adicionadas ao projeto.

Version 0.28

20/10/2026

GIF color fidelity

  • Replaced the fixed low-resolution color palette with one adaptive palette shared across the GIF's frames.
  • Added color dithering to preserve gradients and reduce visible banding.

Version 0.27

20/10/2026

Random player controls

  • Removed selected video filenames from the page display.
  • Added a volume slider below the player that remains consistent when videos switch.

Version 0.26

20/10/2026

Language selector

  • Fixed the desktop language menu being covered by page content, so language choices are clickable.
  • Replaced the language abbreviation in the selector with the country's flag and the language name.

Version 0.25

20/10/2026

Random video player

  • Added a single-player video queue that randomly selects and plays one chosen video at a time.
  • Added a configurable display duration, set to 30 seconds by default, and an option to start each video at a random position.

Version 0.24

20/10/2026

Video Rhythm horizontal track

  • Removed the visual game overlay from the video and kept the rhythm animation in the track below it.
  • All enabled orb colors now travel toward one shared target on the left side of the track.

Version 0.23

20/10/2026

Video Rhythm color track

  • Added a horizontal rhythm track synchronized with video playback, with colored orbs moving toward matching targets.
  • Added color selection in game settings, with pink enabled by default and at least one color always active.

Version 0.22

20/10/2026

Video Rhythm instructions

  • Added a How to Play popup next to the difficulty selector, with placeholder instructions and keyboard-friendly close behavior.

Version 0.21

20/10/2026

Video Rhythm minigame

  • Replaced the reserved fourth page with a video rhythm game that overlays randomized falling orbs and glowing targets on video playback.
  • Added Easy, Normal, Hard, and Expert patterns with different speeds, gaps, and simultaneous notes.

Version 0.20

20/10/2026

Working loop fade effects

  • Connected the fade toggle and duration control to video opacity and audio volume at the selected loop boundaries.
  • Applied the fade consistently during forward and backward playback.

Version 0.19

20/10/2026

Loop reverse audio and visual improvements

  • Added choices to mute audio, keep it playing forward, or play the captured audio backward during the visual reverse pass.
  • Improved reverse-video sharpness and frame pacing, and aligned the reverse preview over the video.
  • Audio modes support selected segments up to 120 seconds.

Version 0.18

20/10/2026

MP4 compatibility remux

  • Added local MP4 remuxing to produce a conventional file layout that improves timeline seeking and compatibility with desktop media players.
  • Preserves supported audio and video codecs without re-encoding and reports when the original audio track cannot be retained.

Version 0.17

20/10/2026

MP4 clip export

  • Clip creation now requests MP4 recording and downloads only recordings confirmed as MP4.
  • Browsers without MP4 MediaRecorder support show an explicit message instead of exporting a different format.

Version 0.16

20/10/2026

Video clip export

  • Enabled clip creation from the selected video segment, retaining its resolution and audio while recording in high quality.
  • Removed the fixed duration limit for clips; recording runs in real time and uses available device memory.
  • Kept the 30-second limit for GIFs while allowing the shared timeline selection to span longer clips.

Version 0.15

20/10/2026

Working forward-and-backward loop

  • Connected the forward-and-backward setting to loop playback using a bounded frame cache, with audio muted during reverse playback.
  • Moved loop settings next to the video selection button.
  • Fade controls remain available in settings but are not connected to playback yet.

Version 0.14

20/10/2026

Loop effect settings

  • Added a settings panel for forward-and-backward playback and video/audio fade options, including a fade duration control.
  • Added the loop settings panel and fade duration controls.

Version 0.13

20/10/2026

Video loop and home grid layout

  • Added a video loop page with adjustable start and end markers for continuous playback of a selected segment.
  • Centered the home video grid on wide screens and improved footer placement.

Version 0.12

20/10/2026

GIF timeline zoom

  • Replaced video scrubbing with timeline zoom, spreading the GIF selection handles for precise editing on long videos.
  • The zoomed timeline can be scrolled horizontally, and the newest patch notes now appear first.

Version 0.11

20/10/2026

Exportação de GIF

  • Geração e download local de GIF usando o trecho selecionado.
  • Limite do trecho aumentado para 30 segundos, a 10 quadros por segundo e largura máxima de 480 px.
  • Os marcadores se ajustam para manter a seleção dentro do limite e mostram a prévia no vídeo conforme são movidos.

Version 0.10

20/10/2026

Rodapé e notas de atualização

  • Adição de um rodapé compartilhado com acesso às notas de atualização.
  • Criação desta página para documentar as atualizações do projeto.

Version 0.9

Interface do criador de mídia
